# Nova AI Singularity Edition

Phase 10 of the ultimate Android AI assistant.

## 🚀 Quick Start

1. Clone this repository
2. Open in Android Studio OR push to GitHub for automatic APK build
3. Install APK on Android device (API 24+)
4. Configure Gemini API key in Settings
5. Grant Accessibility + Notification permissions
6. Start talking!

## 🔧 GitHub Actions Auto-Build

This project includes a GitHub Actions workflow that automatically builds a debug APK on every push to `main` branch.

To trigger a build:
```bash
git add .
git commit -m "Your changes"
git push origin main
```

Download APK from Actions tab → Artifacts section.
